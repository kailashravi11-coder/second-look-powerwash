# Public Images Directory

You can place your website images in this folder!

In your React components or HTML, any image placed here can be accessed directly from the root path:
`/images/your-image-name.jpg` (or `.png`, `.webp`, etc.)

Example:
If you save an image here as `my-house.jpg`, you can display it in code like:
`<img src="/images/my-house.jpg" alt="House" />`
